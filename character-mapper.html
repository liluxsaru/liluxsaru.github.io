Files can be dropped for one or multiple characters at once, in any order/batches - they're grouped by name automatically. Required per character: name.air, sprite_atlas_name.png, sprite_atlas_name.csv (all three needed for preview and hitboxes). Anything else (wrong extension, or a name that doesn't match the pattern above) is skipped and reported below instead of silently ignored.

Avatar (character-select screen, 360×384)

Step to the frame you want on the select screen (usually a clean standing/idle pose) with the animation controls above, then click "Use current preview frame" - the sprite's opaque pixels are auto-cropped and cover-fit into a fixed 360×384 canvas (every character ships the same portrait size, matching lite-fighter.html's select-screen card 1:1) instead of sitting in a sea of padding. Or upload a separate reference image instead - it gets the same fixed-size treatment. Both export files go under assets/{name}/ alongside the sprite atlas - see lite-fighter.html's avatarImages/iconImages loaders.

Command Moves (motion-input Hyper combos)

Motion-input specials (e.g. quarter-circle-forward + a button) recognized by the engine's CommandBuffer off the same held-direction state driving tilts/smashes - works from keyboard or the Xbox 360 stick/d-pad alike. Each entry needs its own unique key (used internally, never shown to players) and a real action number from this character's own .air.

Summons (companion assist pool)

Optional character-specific companion pool (e.g. SpongeBob's Sandy/Squidward/Mr. Krabs) - rendered from THIS character's own atlas, no separate sprite sheet needed. A character with no summons defined here simply has no summon move.
